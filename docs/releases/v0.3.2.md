PassWards 0.3.2 improves the browser extension and adds Brave setup support.

- Refreshed English extension popup with account search and connection status; Persian translations remain disabled.
- Automatic browser connection from the extension popup, without entering a pairing code. Filling and saving still require approval in the desktop app.
- Brave support in browser setup and Windows native messaging registration, alongside Chrome and Edge.
- A short Devtune introduction when the desktop app starts.
- A dedicated TypeScript check for the frontend and build configuration.

Download **PassWards-0.3.2-windows-x64.exe**, or extract the portable ZIP and open **PassWards.exe**. The app includes extension version 0.5.4. Open Settings → Browsers to prepare the extension; reload an existing unpacked extension after replacing its files. Use Repair connection if you move the executable.

Requires Windows 10/11 x64 and Microsoft Edge WebView2 Runtime. SHA-256 checksums are provided in SHA256SUMS.txt. There is no installer or automatic updater.

This is an unsigned early release and has not had an independent security audit. Keep an encrypted backup and remember your master passphrase; forgotten master passwords cannot be reset. Replacing the executable leaves the encrypted vault in your Windows user profile.
