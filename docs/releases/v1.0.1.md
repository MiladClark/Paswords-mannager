PassWards 1.0.1 updates the Windows app and browser extension together.

- Deleting an item and signing out use matching dialogs and ask for the master password. For item deletion, **Don't ask again** skips confirmations until the app is restarted. Signing out always asks for the master password and clears local app data.
- Setup, unlock, and backup recovery forms sit directly on the app background.
- The extension popup has rounded corners and clearer feedback when it cannot connect to the desktop app.

Windows downloads include the installer and portable x64 builds. For Chrome, Edge, or Brave, extract the extension ZIP, enable **Developer mode** on your browser's extensions page, and choose **Load unpacked**. Select the folder containing `manifest.json`, then open **Settings → Browsers** in PassWards to set up the connection.
