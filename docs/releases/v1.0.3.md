PassWards 1.0.3 adds confirmed cloud sync and reorganizes settings.

- Connect DevTune from the toolbar, then use **Sync** to review and merge the latest encrypted cloud backup. Identical items are skipped, different versions are preserved separately, and the combined vault is backed up without deleting local items. Backups from another vault may require their original master password.
- Sync reuses network connections and encrypted downloads when retrying a backup password. Network waits are bounded, upload failures are checked, and the dialog shows the current stage. Retrying an unchanged upload preserves its reservation instead of starting a conflicting upload.
- Settings now groups sync and backups, security, browsers, and app preferences. Connecting or syncing returns to the vault. Browser save and fill requests also open the vault automatically; approved saves select the resulting item.
- The update widget follows the app's light and dark themes. Browser integration continues through the existing extension.

Windows downloads include the portable x64 executable and ZIP, the signed update installer, `latest.json`, checksums, and the unpacked browser extension. DevTune reads this stable GitHub release automatically; its download page and update feed refresh through their existing five-minute caches.

For Chrome, Edge, or Brave, extract the extension ZIP and choose **Load unpacked** on the browser's extensions page. Existing unpacked installations can replace their files and choose **Reload**. This release updates the extension's version metadata; its browser behavior is unchanged.
