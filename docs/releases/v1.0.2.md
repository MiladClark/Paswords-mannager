PassWards 1.0.2 updates the Windows app and browser extension.

- When the vault is unlocked, saving a new login from the browser requires a click on **Save login** in PassWards. Updating an existing login still requires the master password.
- Login suggestions are shown in the extension popup in the browser toolbar. PassWards no longer adds controls below or beside website login fields.

For Chrome, Edge, or Brave, extract the extension ZIP and choose **Load unpacked** on the browser's extensions page. If you already use the unpacked extension, replace its files and click **Reload**. Refresh any open login tabs after updating.
