PassWards is an offline password vault for Windows, with a companion Chrome and Edge extension.

- Save new browser logins, review changed passwords, and fill matching accounts with desktop approval.
- Search and organize accounts with folders, tags, favorites, and encrypted password history.
- Use the master password for vault unlock and sensitive approvals; no separate PIN.
- Keep encrypted backups, automatically lock the vault, and expire copied secrets from the clipboard.
- Updated PassWards branding and a clean source layout at the repository root.

Download **PassWards-0.3.1-windows-x64.exe**, or extract the portable ZIP and open **PassWards.exe**. There is no installer or automatic updater. The extension is included in the app; open Settings → Browsers to set it up. Use Repair connection when switching executable locations.

Requires Windows 10/11 x64 and Microsoft Edge WebView2 Runtime. SHA-256 checksums are provided in SHA256SUMS.txt.

This is an unsigned early release, not an independently audited security product. Start with test data, remember your master passphrase, and keep an encrypted backup. Forgotten master passwords cannot be reset. Moving or replacing the EXE does not move or delete the encrypted vault in your Windows user profile.
