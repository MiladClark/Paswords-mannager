PassWards 1.0.0 brings the desktop app and browser extension to a shared version.

- Settings opens inside the app window. Sign out can erase the local vault, automatic backups, preferences, and browser connections after written confirmation and master password verification. Cloud backups and exports saved outside the app data folder are kept.
- The setup, unlock, and backup recovery screens share a new layout. The DevTune button opens the browser for both sign-in and registration. A local vault can still be created directly in the app.
- Windows downloads include the portable x64 executable and ZIP. Open Settings → Browsers to set up the bundled extension.
